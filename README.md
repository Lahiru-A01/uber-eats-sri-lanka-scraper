# Uber Eats Sri Lanka Store Scraper

## Project Goal

Build a Python-based web scraping project using Playwright to collect publicly available Uber Eats store information for locations in Sri Lanka.

## Technologies

- Python
- Google Colab
- Playwright
- Git
- GitHub

## Initial Objective

1. Understand Playwright.
2. Open the target website.
3. Understand the website structure.
4. Handle location selection.
5. Discover available stores.
6. Handle pagination and infinite scrolling.
7. Extract store information.
8. Clean and validate the collected data.
9. Remove duplicate stores.
10. Save the data.
11. Analyze the data using Google Colab.

## Initial Data

The initial store information we want to investigate includes:

- Store ID
- Store name
- Category
- Rating
- Review count
- Address
- City
- Store URL
- Scraped date/time
